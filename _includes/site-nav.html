{% comment %} Navigation bar for every page except the home page. The home page has the desk (desk-header.html), whose links are the same list of profiles shown here: layers of kind `link` in _data/desk.yml. This is the compact version of those controls for the other pages, with a way back home and the colour theme control. Wide screens show the links and the theme control in the bar. Narrow screens show a menu button instead, which opens them in a drawer (Avanti's .navbar, built on the HTML popover attribute, so it works without JavaScript). Pages with a hero image (`image` in the front matter) start with the bar translucent over the image, so it neither hides the picture nor stands out from it. The siteNav component (_resources/js/components/site-nav.ts) makes it solid again once the image has scrolled away; without JavaScript it is solid from the start (see style.css). Usage: {% include site-nav.html %} (once, at the top of ) Data: _data/desk.yml Styling: Avanti's .navbar. The colours are --site-nav-* in theme.css and the rules that apply them, with the hero tweaks, are in site-nav.css. {% endcomment %}
